# English Hero

منصة مجانية لتعلّم الإنجليزية من الواجهة العربية، مبنية حاليًا كصفحة ويب ثابتة مع حفظ محلي ومزامنة اختيارية عبر Supabase.

## الموقع
https://mrwael1773.github.io/english-hero/

## المزايا الموجودة
- مكتبة تضم 6000 كلمة إنجليزية فريدة مع ترجمات وأمثلة تعليمية.
- مكتبة قواعد وأزمنة مع أمثلة.
- اختبارات تفاعلية مع سجل نتائج، وإحصائيات للدقة والتقدم، ومراجعة للأخطاء مع الإجابة الصحيحة.
- مستويات خبرة وأوسمة إضافية ومسار تعلّم متدرّج يتقدم مع إنجاز الدروس.
- لوحة نشاط أسبوعي وسجل لآخر الاختبارات، محفوظان محليًا ضمن تقدم المستخدم.
- تدريب محادثة وتمارين نطق باستخدام ميزات المتصفح المدعومة.
- ملف إنجازات، اسم عرض، وتصدير/استيراد نسخة احتياطية.
- مكتب الطالب: أضف مهام المذاكرة والواجبات حسب المادة، وحدد المكتمل منها، وتابع التقدم؛ تُحفظ المهام محليًا على الجهاز دون رصيد أو مشتريات.
- عزل تقدم الحسابات عند تبديل المستخدمين، مع إمكانية دمج واستعادة النسخة المحلية الخاصة بكل حساب من صفحة ملف الإنجازات.
- حفظ محلي ومزامنة اختيارية مع حساب Supabase.
- تطبيق ويب قابل للتثبيت، مع Service Worker للعمل عند انقطاع الاتصال لبعض الموارد.

## البنية التقنية
- `index.html`: الواجهة والمنطق التعليمي.
- `pro-dashboard.js`: لوحة الإحصائيات، المستويات، مسار التعلّم، سجل الاختبارات والأخطاء.
- `vocabulary-6000.json`: قائمة الكلمات الشائعة، مرتبة وفق المصدر التكراري وليست تصنيفًا رسميًا لمستويات CEFR.
- `config.js`: عنوان Supabase والمفتاح العام القابل للنشر فقط.
- `cloud-sync.js`: تسجيل الدخول ومزامنة تقدم المستخدم.
- `sw.js`: التخزين المؤقت وتحديث نسخة التطبيق.
- `supabase/migrations/`: تغييرات قاعدة البيانات التي يجب أن تتطابق مع سجل migrations في المشروع.

لا تضع أبدًا `service_role` أو `sb_secret_...` في ملفات الواجهة العامة. حماية البيانات تعتمد كذلك على سياسات RLS الصحيحة.

## التحقق التلقائي
عند رفع تغييرات إلى `main` أو `master`، يعمل GitHub Actions للتحقق من:
- صحة صياغة JavaScript المضمن في الصفحة.
- وجود عناصر الواجهة الضرورية ومكتب الطالب وإدارة مهامه.
- تطابق إصدار تسجيل Service Worker مع اسم ذاكرة التخزين المؤقت.
- سلامة ملف JSON الخاص بالكلمات وعدد الكلمات وعدم التكرار.
- وجود ملف migration الأمني المتعقب وعدم وجود مفاتيح خادمية في إعداد الواجهة.

يمكن تشغيل الفحوص محليًا باستخدام Node.js 22:

```bash
node scripts/validate-project.mjs
```

## مبدأ التصميم
- الميزات التعليمية تعمل دون أي تكامل ذكاء اصطناعي أو مشتريات داخل الموقع.
- الإحصائيات وسجل الاختبارات والأخطاء تُحفظ محليًا على الجهاز، وتخضع المزامنة عبر Supabase لإعداد الحساب وسياساته.

## إعدادات إنتاج تحتاج مراجعة في لوحة Supabase
1. تفعيل حماية كلمات المرور المسرّبة في إعدادات Authentication / Password Security.
2. التأكد من إعدادات تأكيد البريد الإلكتروني وإرسال الرسائل وGoogle OAuth إن كانت مطلوبة.
3. اختبار التسجيل وتسجيل الدخول والمزامنة واستعادة التقدم من متصفح أو جهاز آخر.
4. مراجعة تنبيهات Supabase الأمنية دوريًا.

وجود ملفات الإعداد لا يثبت وحده أن كل مسارات المصادقة تعمل في الإنتاج؛ يجب اختبارها باستخدام حساب تجريبي حقيقي دون مشاركة كلمة مرورك.
